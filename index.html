자주 사용하는 문법을 종류별로 정리했습니다. 입력 예시를 그대로 복사해 사용할 수 있으며, 저장 전에 미리보기로 결과를 확인하세요.

문단과 제목

입력설명
== 제목 ==문단 제목
=== 제목 ===하위 문단 제목
==== 제목 ====세부 문단 제목
----가로 구분선
[br]줄바꿈
[clearfix]좌우 정렬 요소 아래로 흐름 정리

글자 꾸미기

입력설명
'''굵게'''굵은 글씨
''기울임''기울임
__밑줄__밑줄
~~취소선~~취소선
^^위첨자^^위첨자
,,아래첨자,,아래첨자
{{{+1 큰 글씨}}}글자 크기 조절
{{{#red 빨간 글씨}}}글자 색상 지정

링크와 각주

입력설명
[[문서명]]위키 문서 링크
[[문서명|표시할 글자]]링크에 표시할 문구 지정
[[문서명#s-1]]문서의 특정 문단으로 이동
[https://example.com 링크]외부 링크
[* 각주 내용]각주 추가
[anchor(이름)]문서 내 이동 지점 생성
[[분류:분류명]]문서를 분류에 등록

목록과 표

입력설명
* 항목글머리 목록
1. 항목번호 목록
|| 항목 || 항목 ||표의 한 행
||<tablewidth=500> 내용 ||표 너비 지정 예시
||<:> 가운데 ||셀 내용 가운데 정렬
||<-2> 내용 ||셀을 가로로 합치기

이미지와 특수 기능

입력설명
[[파일:이름.png]]이미지 삽입
[[파일:이름.png|width=300]]이미지 너비 지정
[[파일:이름.png|align=right]]이미지 오른쪽 정렬
[목차]문서 목차 표시
[목차(hide)]접힌 목차 표시
[date] · [datetime]날짜 또는 날짜와 시간
[ruby(漢字,ruby=かんじ)]루비 문자 표시

고급 문법

입력 시작설명
{{{#!folding 제목접을 수 있는 영역
{{{#!wiki style="..."스타일 영역
{{{#!latexLaTeX 수식 영역
{{{#!syntax python코드 구문 강조
{{{#!if docName == "문서명"문서 조건에 따른 내용 표시

{{{#!linkcolor
light: #0969da
dark: #79c0ff

visited-dark: #c297ff
hover-light: #0550ae
hover-dark: #a5d6ff
}}}
