나무마크 문법 안내

AonWiki에서 지원하는 나무마크 문법을 설명합니다. 편집 후 미리보기에서 Worker가 렌더링한 결과를 확인하고 저장하세요.

AonWiki는 나무위키 계열 문법을 기반으로 하지만 모든 나무위키 확장 문법·외부 서비스·위젯을 완전히 동일하게 지원하지는 않습니다. 아래 예제는 현재 AonWiki 파서 구현을 기준으로 합니다.

1. 제목과 문단

문법설명
== 제목 ==문단 제목과 목차 항목 생성
=== 하위 제목 ===하위 문단. 등호 2~6개 지원
----가로 구분선
[br]줄바꿈
[clearfix]떠 있는 요소 아래에서 문서 흐름 정리
== 운영 안내 ==
본문 첫 문장입니다.

=== 담당 업무 ===
담당 업무를 적습니다.

3. 내부 링크와 외부 링크

문법설명
[[문서명]]다른 문서로 이동
[[문서명|표시 문구]]링크 표시명 지정
[[문서명#s-1]]특정 문단으로 이동
[https://example.com|공식 사이트]외부 링크

존재하지 않는 내부 문서는 빨간색으로 표시됩니다. 표 안의 링크도 같은 원칙이 적용됩니다.

5. 표

|| 이름 || 담당 업무 ||
|| 아온 || 서버 운영 ||
|| 코지 || 운영 지원 ||
구분문법 예시기능
표 너비·높이<tablewidth=600>, <tableheight=300>표 외부 폭 및 높이 지정
표 정렬<tablealign=center>, <tablealign=right>가운데 또는 오른쪽 배치
표 배경·글자색<tablebgcolor=#eeeeee>, <tablecolor=#222222>표 전체 색상
표 테두리·클래스<tablebordercolor=#888888>, <tableclass=custom>표 테두리 색 및 클래스
표 내부 정렬<tabletextalign=center>표의 기본 텍스트 정렬
행 옵션<rowbgcolor=#eeeeee>, <rowcolor=#222222>, <rowtextalign=center>행 배경·글자색·정렬
열 옵션<colbgcolor=#eeeeee>, <colcolor=#222222>, <coltextalign=center>열 배경·글자색·정렬
셀 옵션<bgcolor=#eeeeee>, <color=red>, <width=180>, <height=50>배경·글자색·너비·높이
셀 정렬<(>, <:>, <)>왼쪽·가운데·오른쪽
병합<-2>, <|2>가로 2칸·세로 2행 병합
세로 위치·여백<^|2>, <v|2>, <nopad>세로 정렬·셀 여백 제거

셀 앞에 옵션을 적어 해당 셀 또는 행·열에 적용합니다. 여러 옵션을 사용할 때는 <bgcolor=#eeeeee><color=#222222>처럼 이어서 적습니다.

표가 화면보다 넓으면 표 컨테이너 하나에서 가로 스크롤됩니다. 문서나 접기 영역 전체에 중복 스크롤이 생기는 것은 의도한 동작이 아닙니다.

6. 접기와 펼치기

{{{#!folding 접기 제목
접었을 때 숨겨지는 본문입니다.
이 안에도 문법과 표를 넣을 수 있습니다.
}}}

접기 제목을 누르면 본문이 열리고 다시 누르면 닫힙니다.

7. 문서 삽입

[include(문서명)]
[include(문서명, 변수=값)]

다른 문서의 내용을 현재 문서에 포함합니다. 존재하지 않는 대상은 빨간 링크로 표시됩니다.

8. 이미지와 분류

[[파일:이미지.png]]
[[파일:이미지.png|width=300&height=180&align=center]]
[[파일:이미지.png|width=320&bgcolor=#eeeeee&border-radius=8]]
[[분류:운영]]
이미지 옵션설명
width, height이미지 너비와 높이
align=left|center|right이미지 정렬
bgcolor이미지 영역의 배경색
theme=dark|light특정 테마에서 표시하도록 지정
border-radius모서리 둥글기
rendering=pixelated픽셀 이미지 렌더링 방식 지정

파일이 등록되어 있지 않으면 업로드가 필요한 링크로 표시됩니다. [[분류:이름]]은 문서 분류로 처리됩니다.

9. 각주와 앵커

본문 내용[* 출처 또는 보충 설명]
[anchor(운영정책)]
[[운영 정책#운영정책]]

[* 내용]은 각주, [anchor(이름)]은 문서 내 이동 지점을 만듭니다.

10. 매크로

문법기능
[목차], [toc]제목 구조를 바탕으로 목차 생성
[목차(hide)]목차 기본 표시 상태 옵션
[date], [datetime]현재 날짜·시간 문자열
[pagecount]문서 수
[br], [clearfix]줄바꿈, 떠 있는 요소 정리
[age(2000-01-01)]입력한 날짜부터 지난 연수
[dday(2027-01-01)]입력한 날짜와 오늘 사이의 일수
[anchor(문단이름)]문서 안에서 이동할 위치 생성
[ruby(漢字,ruby=かんじ)]루비(후리가나) 표기
[math(x^2+y^2)]수식 렌더링

동영상·외부 미디어 매크로

다음 공급자 이름을 사용합니다. 실제 표시 여부는 각 서비스의 임베드 정책과 콘텐츠 공개 상태에 따라 달라집니다.

[youtube(동영상 ID)]
[youtube(동영상 ID,width=640,height=360,start=30,end=90)]
[nicovideo(sm9)]
[navertv(클립 ID)]
[kakaotv(클립 ID)]
[vimeo(동영상 ID)]
[instagram(게시물 ID)]
[twitter(게시물 URL)]
[tiktok(동영상 ID)]
[facebook(게시물 URL)]

width와 height로 크기를 지정할 수 있으며, YouTube는 start와 end 재생 구간도 지원합니다.

매크로는 대소문자를 구분하지 않도록 처리되어 있습니다. 다만 서비스 측에서 임베드를 제한하거나 삭제한 콘텐츠는 표시되지 않을 수 있습니다.

11. 코드·위키·수식 블록

{{{#!syntax python
def hello():
    print("Hello, AonWiki")
}}}

#!syntax 뒤에 언어명을 지정하면 코드 블록으로 분리하고 구문 강조를 적용합니다. 지원 언어는 코드 강조 라이브러리에 따라 달라질 수 있습니다.

{{{#!wiki style="border:1px solid #888; padding:10px"
'''위키 문법'''으로 렌더링되는 꾸밈 블록입니다.
}}}

#!wiki는 내부 내용을 나무마크로 렌더링하는 블록입니다. HTML/CSS는 보안 필터를 거치며 임의 스크립트는 실행되지 않습니다.

[math(E = mc^2)]
E = mc^2

수식은 [math(식)] 또는 <math>식</math> 형식으로 작성합니다.

12. 관리자 기능과 저장 전 확인

  • 편집 권한은 로그인과 문서 보호 설정을 따릅니다.
  • 미리보기는 Worker가 실제 파싱한 결과를 표시합니다.
  • 문서 역사에서 원문 차이와 렌더 결과를 비교할 수 있습니다.
  • 이전 버전을 복원하면 복원 전 현재 문서도 새 역사 항목으로 보존됩니다.
  • 교정 BOT은 흔한 오타를 찾아 제안하는 보조 기능이며 문맥형 맞춤법 검사기는 아닙니다. 저장 전에 확인하세요.

지원 범위는 파서 업데이트에 따라 변경됩니다. 불확실한 문법은 실제 서버 미리보기 결과를 기준으로 판단하세요.
